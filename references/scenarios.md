# 场景设计规范

按"受众与场合"分五大类。**受众决定审美标准**：给导师/评审的越克制；给评委的越讲"为什么选我、好在哪"；给老师和同学的越重"讲得清楚"；给面试官的越重"成果与匹配"。

五类共享同一套"去 AI 味 + 导师审美"底座（见 `style-rules.md`），差异在配色、结构、图表与语气。选定类别后，整份 deck 只用这一套规范，不混用。

通用字号（中文演示常规视距）：

| 角色 | 建议 | 说明 |
|---|---|---|
| 页标题 | 26–30pt | 结论式一句话；竞赛/评优可到 32pt |
| 小节标题 | 20–24pt | 可选 |
| 正文 | 16–18pt | 短语，不写整段 |
| 图注 / 表头 | 12–14pt | 编号 + 一句话说明 |
| 大数字 | 40–60pt | 只放大"关键 1 个数" |

字体：中文用思源黑体或微软雅黑（标题加粗、正文常规）；答辩若与论文一致可用宋体正文。英文与数字用 Arial / Source Sans。整套 deck 最多两种字体（中文一套 + 西文一套算一套）。

## 一、学术科研型（给导师 / 评审）

**子场景**：组会进度汇报 · 开题/中期考核 · 学位论文答辩 · 学术会议报告

- **结构**：背景与目标 → 方法 → 结果（核心，占最多页）→ 讨论 → 下一步。
- **配色**：白底 `#FFFFFF`；主色深蓝 `#1F4E79`；强调蓝 `#2E75B6`；浅灰底卡 `#F2F4F6`；正文 `#1A1A1A`、次要 `#555555`。图表蓝系 `#1F4E79 → #5B9BD5 → #9DC3E6`。
- **版式**：严格左对齐网格；一页一个主图，图占 60–70% 面积；文字是"看图结论"，不复述方法。
- **图表**：折线 / 散点 / 柱状；误差棒、单位、显著性标注齐全；关键点直接标注，不让观众来回对坐标轴。饼图仅在 ≤4 类且占比是主题时用。
- **语气**：克制、留白多、零装饰。
- **子场景差异**：组会汇报重在"这一步为什么做、下一步做什么"；开题/中期重"路线图与已完成度"；论文答辩最克制、图统一编号（图 3-1）、与论文一致；会议报告可在保留严谨下稍微提速、加重"一个结论"。
- **最该修的 AI 味**：渐变底、满屏 bullet、图无图注、名词式标题（"结果分析"）。
- **验收**：每页标题是结论；每图有编号图注；无禁用词；30–60 秒能讲完一页。

## 二、竞赛评审型（给评委）

**子场景**：学科竞赛答辩（挑战杯 / 互联网+ / 大创 / 数模 / 电赛）· 创新创业路演

- **结构**：痛点 → 方案 → 创新点 → 成果与数据 → 团队与展望。
- **配色**：白底；主色**只选一个**——深红 `#C0392B` 或 深蓝 `#0B5394`；强调金 `#F1C40F` 只用小面积（数字高亮），大面积显廉价；文字深灰 `#222`。
- **版式**：关键数字 40–60pt；"传统 vs 本方案"并排对比；每页一个视觉焦点。
- **图表**：对比柱状、雷达图、散点；数据卡片（大数字 + 一句话）。
- **语气**：有冲击力、节奏强、拒绝模板感装饰。
- **子场景差异**：学科竞赛更技术——方法、指标、验证；创新创业路演更商业——价值主张、市场、商业模式、可落地性。
- **最该修的 AI 味**：彩虹渐变、堆 emoji/图标、口号式空洞标题（"智领未来"）。
- **验收**：评委 3 秒能抓到每页的"这一个数字/点"；主色一致；无空口号。

## 三、课程教学型（给老师 / 同学）

**子场景**：课程作业 / 小组汇报 · 文献阅读汇报（journal club）· 课程设计 / 大作业答辩

- **结构**：总起（这页讲什么）→ 分点展开 → 小结；总分总最稳。
- **配色**：白底 / 极浅底 `#FAFBFC`；主色学院蓝 `#2E5A87` 或 青绿 `#0E7C7B`；少量亮色 `#E8A33D` 点缀；正文 `#222`。
- **版式**：结构清晰、段落分明；图表辅助理解；适度留白；不为"炫"牺牲"懂"。
- **图表**：示意图、流程图、对比表优先；复杂公式/代码给"可读片段"而非整屏。
- **语气**：明快、清楚、像"认真备过课的讲解"。
- **子场景差异**：课程汇报重"讲明白一个主题"；文献汇报固定骨架——问题 → 方法 → 结果 → 局限 → 对己启发；课程设计答辩偏"需求 → 方案 → 实现 → 结果"。
- **最该修的 AI 味**：信息堆叠无重点、术语不解释、大段文字贴满屏。
- **验收**：没看过这份材料的人能听懂每页在说什么；术语首次出现有解释；页页有重点句。

## 四、评优展示型（给评委 / 师生）

**子场景**：奖学金答辩 · 社会实践 / 志愿服务汇报 · 学生工作述职 / 竞选

- **结构**：个人 / 团队概览 → 成果与亮点 → 成长与贡献 → 总结表态。
- **配色**：白底；主色深青绿 `#0E7C7B`；强调暖金 `#C9A227` 少量；正文 `#1A1A1A`。
- **版式**：成果卡片、时间线、前后对比；关键指标大数字。
- **图表**：大数字卡片、时间线、柱状对比；**每个亮点都要有数字或成果支撑**。
- **语气**：有温度但不煽情、成果导向、真诚。
- **子场景差异**：奖学金答辩重"学业 + 综合 + 成长的证据链"；社会实践重"做了什么 + 产生了什么影响"；述职/竞选重"干了多少事 + 数据 + 下一步承诺"。
- **最该修的 AI 味**：空洞形容词（"显著提升""大幅改善"）无数字、与内容无关的配图、堆荣誉罗列。
- **验收**：每个"亮点"有数字或成果支撑；无空泛形容词；时间线/对比真实。

## 五、求职升学型（给面试官 / 招生老师）

**子场景**：实习总结 / 转正答辩 · 求职面试 presentation · 考研复试 / 保研夏令营

- **结构**：我是谁（一句话定位）→ 关键经历 / 项目 → 成果与能力 → 匹配与规划。
- **配色**：白底；主色炭灰蓝 `#34495E`；少量亮蓝 `#1F6FEB` 点缀；正文 `#222`。
- **版式**：一页一个亮点；项目用 STAR（情境-任务-行动-结果）讲，每项项目给 1–2 个量化结果；与简历视觉一致。
- **图表**：少而准；用数据证明贡献（提升 X%、产出 Y、覆盖 Z）。
- **语气**：专业、简洁、干练、可信。
- **子场景差异**：实习转正重"我做了什么 + 会留下什么"；求职面试重"能力与岗位匹配"；复试/夏令营重"学术背景 + 研究计划 + 未来方向"。
- **最该修的 AI 味**：套话式自我评价（"学习能力强、善于沟通"无例证）、整屏文字、与岗位无关的罗列。
- **验收**：每页能回答"这证明了我什么能力/匹配点"；量化结果真实；与简历/申请表一致。
