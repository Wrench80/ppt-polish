# 去 AI 味 + 导师审美规则

这部分跨场景通用。核心一条：**把"AI 生成感"换成"训练有素的人做的、给懂行的人看的"**。

## 一、去 AI 味（文字）

### 禁用词表

看到即换，换不成领域语言就删。AI / 互联网黑话一律不用：

> 赋能、助力、闭环、抓手、颗粒度、底层逻辑、顶层设计、深耕、矩阵、生态、打法、心智、占领、新范式、一站式、全链路、异构、范式、智能表征、特征空间、鲁棒、架构、多模态、深度（作形容词时）、显著提升、大幅改善、较好地、有效地、充分、全面、深入、赋能式措辞。

**换法**：换成领域语言或具体数字。
- 光谱类工作：背景、重叠峰、峰位、峰强、分辨能力。
- "显著提升" → 写具体数字："准确率从 82% 到 91%"。
- "充分验证了方法的有效性" → "在 3 个数据集上误差均低于 5%"。

### 标题写法

- **页标题 = 结论或问题**，不是名词标签。
  - ✅ "误差降到 3%，但低频段仍偏高"
  - ✅ "为什么改用时频域表示？"
  - ❌ "结果分析"、"方法介绍"、"性能对比"
- 标题不加句号（除非是完整长句）；正文标点正常。

### 正文写法

- 要点是**短语**，不是整句；一句话一件事。
- 去掉"首先 / 其次 / 最后"式的填充；层级靠排版，不靠连接词。
- 不写修辞问句、口号、押韵对仗。
- 数字、单位、符号前后一致（如 "3.2%" 不要又写 "3.2 个百分点"）。

## 二、去 AI 味（视觉）

出现以下任一条，就按"AI 模板脸"处理，删掉或重构：

1. 紫 / 蓝 / 青的大面积**渐变背景**。
2. **emoji** 或表情符号。
3. 无意义的** 3D 立体形状**、漂浮几何装饰、角落彩条。
4. **纯装饰图标**：与内容无关的手、灯泡、齿轮、握手图。
5. **与数据无关的配图**：只有"好看"没有信息量的图。
6. **软阴影 + 圆角卡片**堆满一页（卡片可以有，但一页别超过一个视觉容器）。
7. **满屏 bullet**：文字墙；一页超过 5 行要点就该拆页或进备注。
8. **居中一切**：标题居中、正文居中、图居中——改成统一左对齐网格。
9. **低对比灰字**：正文 `#999` 以下不可用于正文。
10. **字体混用**：宋体黑体楷体混排、多种西文字体。

## 三、导师眼中的"美"

导师看的是**信息是否可信、是否好读、是否尊重时间**，不是"好不好看"。按这个排序：

1. **准确 > 好看**：数字、单位、结论、图注必须对得上；一处硬编码数字脱节，整份可信度归零。
2. **一致**：页标题同位置、同字体同字号、同一套配色、同样的图注格式、统一的编号（图 3-1、表 2-1）。
3. **克制**：一个强调色、大留白、无动画炫技、无装饰噪音。
4. **数据优先**：图大、字少；轴有标签和单位；误差棒 / 显著性标注；直接标注关键点，不让观众猜。
5. **层级清晰**：标题 > 小节 > 正文 > 图注，一眼能看到路径。
6. **可速读**：一页 30–60 秒能讲完、能看懂；超过就拆页。

## 四、科学边界（不越界，否则返工）

1. 不写因果（"因为 A 所以 B"）——只写观察与关联。
2. 不把低于仪器/方法分辨能力的变化说成"变化"。
3. 不写未经检验的统计推断（如"远超随机水平"）。
4. 不外推到未测样品；单样品结论必须写明"这是代表性样品"。
5. 不确定的信息（样品条件、外部记录）标注"需与记录核对"，不要断言。

## 五、讲稿（Speaker Notes）

- 目标 30–60 秒 / 页，中文按 ≈250 字 / 分钟估算。
- 讲稿解释"这一页为什么必须做、图证明了什么"，不念图。
- 句式参考："我们一开始发现… / 所以这里先… / 这张图证明… / 因此下一步才能…"。

## 六、无渲染工具时的程序化验收

改完 deck 后，若无 soffice / PDF 渲染，按三步核对（用当前环境可用的工具实现）：

1. **布局**：逐形状读 `left/top/width/height` → 检查越界 + 两两重叠（跳过文本框之间；标题框与图轻微相交可接受）。
2. **内容**：抽取全部文本（含表格单元格与备注）拼成全文 → ① 关键数字必须出现；② 禁用词 / 废弃表述为 0；③ 科学边界声明以否定形式在位。
3. **讲稿**：逐页字数 → 折算时长区间。

注意：图内文字（示意图、截图）不在 PPT 文本流里，脚本要区分"正文文本"与"图内文字"，否则会误报缺失。
